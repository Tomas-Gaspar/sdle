## How to build and run

First, navigate to the _src_ folder and install the necessary dependencies:
```bash
$ cd src
$ npm install
```

Next, for each of the following folders: _client_, _proxy_, and _server_, initialize them by running:
```bash
$ cd [client/proxy/server]
$ npm start
```

Lastly, open a web browser and navigate to [Shopify](http://localhost:3000).
